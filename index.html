Guided workflow — four stages

Runs on the CPU alone. If you connect an AI (below), stage 2 and stage 4 can use it. Load the song, paste the original lyrics (optional, if you have them) and your replacement lyrics into the two boxes on the right, then run each stage or Run all, which pauses for your review after stages 1 and 2.

How to paste lyrics
  • Song Shape never downloads lyrics or songs. You load your own audio file and paste the lyrics yourself.
  • Original lyrics (optional): the words of the reference song, if you have them. Without them, place words by clicking, or skip stage 1 and work from the shape only.
  • Your replacement lyrics: the words you want sung with the same delivery.
  • One sung line per line. Leave a blank line between sections. Section names are optional — a line such as [Chorus] only marks where a section starts.
  • Any [bracket] tags and clear performance cues in parentheses such as (whispered) are ignored. Song Shape writes its own tags: [Verse] / [Chorus] (a block that repeats is the chorus) and a [Delivery: …] line built from the measured rise and fall. Unclear parentheses such as (oh oh) stay as sung backing words and are flagged.
  • Leave out titles, credits, chords and notes; they would be read as lyric lines.

Original lyrics (optional — paste if you have them)

Paste the reference song's lyrics yourself; Song Shape never fetches lyrics. Plain lines, blank line between sections. [Bracket] tags and (performance cues) are ignored. Then click the plot in Place-word mode to drop the next word. A word is not a stroke — switch to Trace to draw.

Words in (parentheses) are backing vocals / ad-libs and are not placed unless you turn this on. Bracket cues such as [hold] or [pause: 1 bar] are never placed.

CPU word timing assist

Start with the audio and supplied original lyrics. These two optional actions generate unverified word-position proposals; they do not transcribe words. The first option is more useful after you select a short lyric-line loop on the timeline. Existing anchors are preserved.

Imported timing format: words: [{text, start, end}], using seconds, or start_ms/end_ms. Correct mismatches before import.

Map my lyrics

Paste your replacement lyrics (saved separately in your local Song Shape JSON). Plain lines, blank line between sections; any [bracket] tags or (performance cues) you paste are ignored and replaced by Song Shape's own tags. Copy a reduced-data AI request, or build a contour-directed sheet without AI. Style prompts describe the sound and do not name the artist.

Visual contour on your replacement words. Upload the exported PNG alongside the copied AI text to a vision-enabled model, or use the complete event JSON with a text-only local model. Source audio and original reference wording are not included in shared outputs.

Lyric sheet

Suno-style generators do not guarantee that bracketed cues will be followed. Tags are suggestions, not promised control. The lead identity is written once; harmony cues appear only where you marked backing harmony under that lead.

Draft (measured pitch)

An in-browser pitch and loudness measurement. This is a distinct editable draft layer, not the hand trace of perceived delivery. Measuring a whole song can take several seconds; a 15–20 second view or loop is usually near-instant.

Keep this reference fixed when analyzing multiple sections to preserve relative high/low levels. This is a measured-frequency reference, not the singer's anatomical range. Mixed harmonies can confuse pitch detection.

No GPU or AI required. On isolated lead vocals it can propose a frequency contour automatically, but it is not a verified match for expressive delivery; harmonies and instruments can interfere.

Connect your AI (optional, off by default)

Local (Ollama, LM Studio, llama.cpp) or an API (xAI/Grok, OpenAI, others) through an OpenAI-compatible endpoint. The API key stays in this tab’s memory / sessionStorage and is never written into exports. API providers are remote: tick the LAN/cloud opt-in, and the data in each request leaves your computer. Ollama rejects pages opened from disk: use Serve-Local.cmd.

AI context file

Every AI request starts with the Song Shape context (SONG_SHAPE_AI_CONTEXT.md) so the model knows the tool, the stages, the data and the Suno tag rules. You can load your own version for this tab.

AI learns from your hand traces

Pick finished hand-traced projects as examples. The AI drafts the trace window by window (about 12 s, grouped by lyric line) from the locally measured pitch contour plus your placed word timings and syllable counts, then the windows are stitched together; with no examples it drafts from that evidence alone. AI strokes appear dashed and tagged ai_drafted_trace / needs_review: correct them by ear (delete, or redraw in Trace mode). Examples stay in this tab only and are never saved or exported. Nothing is sent until you click Draft.

    For many songs without hand work, use the command line: node cli/songshape.js ai-batch <folder> -o <out> --endpoint … --model … (see README).
