# Song Shape v0.2.9 — privacy model

The primary app runs as a static offline HTML page; audio processing, hand tracing, word-position estimates and exports require no hosted server, account, telemetry or internet. The optional Node CLI also runs locally and never makes a network request.

The **editable project** (`Export JSON` or `project.json`) intentionally stores the original reference lyrics, word anchors, machine drafts and user edits so work can resume. It includes the source audio **filename/duration**, **not audio bytes**. Keep this file local unless you explicitly choose to share it.

The **AI-oriented artifacts** (`ai-request.txt`, `ai-handoff.json`, `visual-map.svg`, `songshape-visual-handoff.png`, and `visual-handoff.html`) include **your replacement lyrics** and derived contour/timing events by default; they omit original reference lyric text, source artist shortcut and audio bytes. Filename defaults for AI sharing are neutral rather than named after the source recording. User-entered free-text singer identity or directions may still contain identifying information: review before sharing.

**Connect your AI** is optional, disabled by default, and requires an explicit Send action. Sending to LAN/cloud endpoints requires an additional per-page opt-in. The API key stays in this tab's memory/sessionStorage and is not part of project or AI-artifact exports. **AI learns from your hand traces** sends, only when you click **Draft trace with AI**, a compact measured pitch contour of the loaded song plus the hand strokes of up to five examples you chose — never audio bytes, lyrics or file contents beyond the example labels. Examples are held in the tab's memory and never saved. The CLI `ai-draft`/`ai-batch` commands send the same data per song only when you run them; non-local endpoints need `--allow-remote`, and an API key is read only from an environment variable you name. A `localhost` AI gateway may itself be cloud backed, depending on its configuration; verify that your LLM really runs locally for strict offline inference.

**What each AI call sends (v0.2.8).** Every call starts with the AI context text (`SONG_SHAPE_AI_CONTEXT.md` or your override) — instructions only, no user data. *Stage 2 (draft the shape)*: per line window, the measured pitch grid, line start/end times, placed word onset times and estimated syllable counts, and your chosen examples' hand strokes; the reference word text **only** if you tick "Include the original word text" / pass `--send-word-text`. *Stage 4 (final sheet)*: the same reduced handoff as `ai-request.txt` (your new lyrics, projected words, events per line, warnings, your lead identity) — not the reference lyrics. Never audio bytes, files or keys. **The xAI and OpenAI presets are remote services**: using them sends this data to that company under your own account and their terms; they need the explicit remote opt-in (browser) or `--allow-remote` (CLI). CLI keys are read only from environment variables. The optional `--separator` / `--aligner` tools run locally as programs you chose; Song Shape passes them file paths only.

**Lyrics are never fetched.** Song Shape does not look up or download lyrics or songs; it only uses the text you paste or the files you pass to the CLI.

The original Song Shape has no tracking, analytics, accounts or data collection. Use the official repository as the verified source; copies from elsewhere may have been modified.

No other software is installed, model weights downloaded, telemetry enabled or internet access initiated by Song Shape. Users should obtain permission for reference recordings and original lyric content as necessary.
